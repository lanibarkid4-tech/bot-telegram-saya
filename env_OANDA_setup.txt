========================================
   SETUP OANDA API KEY - 5 LANGKAH
========================================

LANGKAH 1: Daftar Akun OANDA Demo (GRATIS)
- Buka: https://www.oanda.com/register/
- Pilih "Demo Account" (Practice, gratis, no deposit)
- Isi data, verifikasi email

LANGKAH 2: Generate Personal Access Token
- Login ke OANDA
- Buka: https://www.oanda.com/account/tpa/personal_token
- Pilih akun Practice (demo)
- Klik "Generate"
- Token akan muncul (contoh: 0123456789abcdef0123456789abcdef-0123456789abcdef0123456789abcdef)
- COPY token tersebut

LANGKAH 3: Dapatkan Account ID
- Login ke OANDA
- Klik "My Accounts" di dashboard
- Lihat "Account ID" (contoh: 001-001-1234567-001)
- COPY account ID

LANGKAH 4: Edit File .env
- Buka file .env di folder ini dengan Notepad
- Tambah 2 baris di bawah TELEGRAM_BOT_TOKEN:
    OANDA_API_KEY=token_disini
    OANDA_ACCOUNT_ID=account_id_disini
- Save

CONTOH FILE .env LENGKAP:
----------------------------------------
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
OANDA_API_KEY=0123456789abcdef0123456789abcdef-0123456789abcdef0123456789abcdef
OANDA_ACCOUNT_ID=001-001-1234567-001
----------------------------------------

LANGKAH 5: Restart Bot
- Stop bot (Ctrl+C)
- Run ulang: npm start
- Akan muncul: ✅ OANDA_API_KEY loaded (forex signal aktif)

CATATAN PENTING:
- OANDA DEMO account GRATIS, tidak perlu deposit
- Token API di OANDA tidak ada masa berlaku, tapi bisa di-revoke
- JANGAN SHARE token Anda ke orang lain
- Kalau signal masih error, hubungi saya dengan error log
