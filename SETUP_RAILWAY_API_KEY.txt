========================================
   SETUP API KEY DI RAILWAY (2 MENIT)
========================================

LANGKAH 1: Buka Railway Dashboard
-----------------------------------
Klik link ini (sudah login otomatis kalau pernah):
https://railway.app/dashboard

LANGKAH 2: Pilih Project Bot Anda
-----------------------------------
- Klik project yang ada tulisan "telegram-bot2" atau nama bot Anda

LANGKAH 3: Buka Tab Variables
-----------------------------------
- Di project page, klik tab **"Variables"** (di tengah, ada icon kunci 🔑)
- Anda akan lihat daftar variable yang sudah ada:
  * TELEGRAM_BOT_TOKEN = ***

LANGKAH 4: Tambah Variable Baru
-----------------------------------
- Klik tombol **"+ New Variable"** atau **"RAW Editor"** (lebih cepat)
- Masukkan:

  Variable 1:
  -----------
  Name:  TWELVE_DATA_API_KEY
  Value: c9e648ef65784638ac68a965beee7ff6

  Variable 2 (kalau belum ada):
  -----------
  Name:  TELEGRAM_BOT_TOKEN
  Value: (paste token dari file .env lokal Anda)

LANGKAH 5: Save
-----------------------------------
- Klik **"Add"** atau **"Save"**
- Railway akan auto-redeploy dalam 1-2 menit

LANGKAH 6: Cek Log
-----------------------------------
- Klik tab **"Deployments"** → klik deployment terbaru
- Lihat log, harus muncul:
  ✅ TWELVE_DATA_API_KEY loaded (forex signal aktif)
  ✅ BOT BERHASIL DIJALANKAN!

LANGKAH 7: Test di Telegram
-----------------------------------
- Buka Telegram, chat dengan bot Anda
- Kirim: /signal XAUUSD
- Harusnya dapat analisa Gold lengkap

========================================
   ALTERNATIF: Pakai RAW Editor (Lebih Cepat)
========================================

1. Klik tab "Variables"
2. Klik tombol "RAW Editor" (icon {} di kanan atas)
3. Paste:

```
TWELVE_DATA_API_KEY=c9e648ef65784638ac68a965beee7ff6
TELEGRAM_BOT_TOKEN=8803384308:AAENd6NH8T2RWBcovHVeGZbO_QLH6gUEecA
```

4. Klik "Save" atau "Update"

========================================
   KENAPA SAYA TIDAK BISA LANGSUNG SET?
========================================

- Railway dashboard butuh login (OAuth + browser)
- Tidak ada public API untuk set variable tanpa auth
- Railway CLI perlu di-install (gagal karena network)
- Repo GitHub PUBLIC, tidak bisa commit .env (token akan terekspos)
