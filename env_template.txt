========================================
   BUAT FILE .env DI FOLDER INI
========================================

1. Klik kanan di folder ini -> New -> Text Document
2. Beri nama file: .env  (ada titik di depan, tidak ada .txt)
3. Isi dengan teks di bawah ini:

----------------------------------------
TELEGRAM_BOT_TOKEN=paste_token_anda_disini
OANDA_API_KEY=paste_oanda_token_disini
OANDA_ACCOUNT_ID=paste_account_id_disini
----------------------------------------

Ganti "paste_token_anda_disini" dengan token dari BotFather.
Ganti "paste_oanda_token_disini" dengan OANDA API token.
Ganti "paste_account_id_disini" dengan OANDA Account ID (numeric).

LANGKAH MEMBUAT TELEGRAM TOKEN:
1. Buka Telegram
2. Cari @BotFather
3. Ketik /newbot
4. Ikuti instruksinya
5. Copy token yang diberikan
6. Paste di file .env

LANGKAH MEMBUAT OANDA API KEY:
1. Daftar akun OANDA (demo gratis): https://www.oanda.com/register/
2. Login → https://www.oanda.com/account/tpa/personal_token
3. Klik "Generate Personal Access Token"
4. Copy token (contoh: 0123456789abcdef...)
5. Catat juga Account ID (numeric, contoh: 001-001-1234567-001)
6. Paste di file .env

CATATAN:
- Akun OANDA DEMO (practice) GRATIS, tidak perlu deposit
- OANDA butuh akun broker (tidak ada tier gratis untuk non-customer)
- Pair OANDA format: EUR_USD (underscore)
- XAU/USD gold spot juga tersedia di OANDA
