========================================
   BUAT FILE .env DI FOLDER INI
========================================

1. Klik kanan di folder ini -> New -> Text Document
2. Beri nama file: .env  (ada titik di depan, tidak ada .txt)
3. Isi dengan teks di bawah ini:

----------------------------------------
TELEGRAM_BOT_TOKEN=paste_token_anda_disini
TWELVE_DATA_API_KEY=paste_twelve_data_key_disini
----------------------------------------

Ganti "paste_token_anda_disini" dengan token dari BotFather.
Ganti "paste_twelve_data_key_disini" dengan API key dari Twelve Data.

LANGKAH MEMBUAT TELEGRAM TOKEN:
1. Buka Telegram
2. Cari @BotFather
3. Ketik /newbot
4. Ikuti instruksinya
5. Copy token yang diberikan
6. Paste di file .env

LANGKAH MEMBUAT TWELVE DATA API KEY (10 DETIK):
1. Buka https://twelvedata.com/pricing
2. Sign up dengan email
3. Verifikasi email
4. Copy API key dari dashboard
5. Paste di file .env

CATATAN TWELVE DATA:
- GRATIS 800 request/hari, 8 req/menit
- Support forex, gold (XAU/USD), indeks (IXIC, GSPC, DJI)
- Pair format: EUR/USD (slash), XAU/USD (gold), IXIC (NASDAQ)
- Demo key (key=demo) bisa untuk forex testing
- Untuk gold & indeks butuh sign up
